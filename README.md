# DocBase

DocBase — это современная внутренняя платформа для хранения корпоративных документов, быстрого полнотекстового поиска и совместной работы с учетом ролей доступа.

## Возможности

- централизованное хранение документов с версионированием;
- загрузка файлов и редактирование текста прямо в браузере;
- гибкая модель ролей (администратор, редактор, наблюдатель);
- удобный поиск по ключевым словам и получение ответов на вопросы на основе текста документов;
- история изменений с указанием редакторов и комментариев;
- эргономичный интерфейс на основе Bootstrap 5.

## Стек технологий

- Python 3.11+
- Flask 2.3
- SQLAlchemy 2.0
- SQLite (по умолчанию)
- Bootstrap 5

## Установка и запуск

1. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте администратора:

   ```bash
   flask --app run.py create-admin
   ```

   При первом запуске команда предложит задать логин и пароль администратора.

4. Запустите приложение:

   ```bash
   flask --app run.py run --debug
   ```

   После старта интерфейс будет доступен по адресу <http://127.0.0.1:5000/>.

## Роли доступа

| Роль         | Возможности |
| ------------ | ----------- |
| Администратор | Управление пользователями, редактирование и удаление документов |
| Редактор      | Создание и редактирование документов |
| Наблюдатель   | Только просмотр документов и поиск |

## Индексация поиска

По мере создания или редактирования документов поисковый индекс обновляется автоматически. При необходимости можно перестроить индекс вручную:

```bash
flask --app run.py reindex
```

## Структура проекта

```
.
├── docbase/
│   ├── __init__.py        # фабрика приложения Flask
│   ├── auth.py            # аутентификация и управление пользователями
│   ├── config.py          # конфигурация приложения
│   ├── documents.py       # маршруты для работы с документами
│   ├── extensions.py      # расширения Flask (SQLAlchemy, LoginManager)
│   ├── models.py          # модели данных
│   ├── search.py          # модуль поиска
│   ├── static/            # статические файлы (CSS)
│   └── templates/         # шаблоны интерфейса
├── instance/              # база данных и приватные настройки
├── requirements.txt       # список зависимостей
├── run.py                 # точка входа
└── storage/               # хранилище загруженных файлов
```

## Тестовые данные

Создайте несколько документов через интерфейс, чтобы наполнить систему. Используйте страницу «Поиск» для проверки релевантности и ответов на вопросы.
